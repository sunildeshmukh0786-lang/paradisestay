# Paradise Stay — Upload Package

This is a complete rebranded copy of the Blossom Stay website. All original villa pages, catalogue data, prices, descriptions and local image assets are retained.

## Deploy
1. Upload **the contents of this folder** to the publishing root of your host/repository.
2. Keep the `public` and `villa-detail` folders in the same structure.
3. The included `CNAME` points to `paradisestay.online`.
4. Configure DNS with your hosting provider/GitHub Pages and enable HTTPS.

Primary contact email used in the site: `hello@paradisestay.online`.
